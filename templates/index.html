FAQ + Field Notes

When do morels usually pop?

Usually in spring, when soils warm into that cozy mid-40s to mid-50s °F zone and the woods have had some good moisture.

Do certain trees really matter?

A lot of hunters swear by mature hardwood areas and indicator trees like elm, ash, apple, and poplar. This tool lets you count that as a small bonus.

What kind of places should I check first?

Start with hardwood edges, south or east-facing slopes early in the season, then damp bottoms and shady spots when it warms up more.

Safety note, woodland princess edition

Never eat a wild mushroom unless you’ve positively identified it. Cute forest vibes do not cancel out poisonous lookalikes.

Citations + How It Works

Where do the numbers come from?

The app uses Open-Meteo for geocoding and weather.

  • Geocoding: Open-Meteo Geocoding API
  • Weather: Open-Meteo Archive API and/or Forecast API

Docs: Geocoding API · Weather API

How does the Python program work?
  • You type a location.
  • Python turns it into GPS coordinates.
  • Python fetches the last ~7 days of weather for that point.
  • Python adds points for soil temp, rain, day temps, night temps, and trees.
  • Python returns a percent score and paints the page with your result.
Tiny version: location -> (lat, lon) (lat, lon) -> weather last 7 days weather -> points -> percent
How does the score work?
  • Soil 45–55°F → +30
  • Rain 0.5–2 inches → +25
  • Day 60–75°F → +20
  • Night above 40°F → +15
  • Trees = yes → +10
Disclaimer: Microclimates and habitat still matter a lot. This is a weather-based estimate, not a promise from the mushroom gods.
